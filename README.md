# Machine-Learning-Project-for-Personality-Prediction

## Overview

This project uses the **Extrovert vs. Introvert Personality Traits Dataset**, a collection of behavioral and social data designed to analyze patterns associated with human personality.

The dataset contains indicators related to extroversion and introversion, including time spent alone, participation in social events, comfort in social situations, and social media activity.

The project demonstrates how data preprocessing, exploratory data analysis, visualization, and machine learning can be used to identify patterns in personality-related data and build a personality classification model.

Potential areas of application and study include:

- Psychology
- Sociology
- Behavioral analysis
- Marketing
- Machine learning and data science

## Objectives

- Explore behavioral patterns associated with extroversion and introversion.
- Clean and preprocess the dataset for machine learning.
- Analyze relationships between personality traits and social behaviors.
- Visualize important patterns and trends in the data.
- Train a machine learning model to classify personality type.
- Evaluate the model's performance and predictions.
- Gain hands-on experience with an end-to-end machine learning workflow.

## Technologies Used

- **Python**
- **Pandas** — data manipulation and preprocessing
- **NumPy** — numerical operations
- **Matplotlib** — data visualization
- **Scikit-learn** — machine learning and model evaluation
- **Jupyter Notebook** — experimentation, analysis, and documentation

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3
- Git
- Jupyter Notebook

### 1. Clone the Repository

Open Terminal and run:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Then move into the project directory:

```bash
cd YOUR-REPOSITORY
```

### 2. Create a Virtual Environment

Creating a virtual environment keeps the project's packages separate from other Python installations.

#### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

#### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Jupyter will open in your browser.

Open:

```text
AI_ML_DT_PersonalityPredictionProject.ipynb
```

Then run the notebook cells in order, or select **Kernel → Restart & Run All**.
